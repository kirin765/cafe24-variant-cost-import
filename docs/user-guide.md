# 사용자 안내 — 품목별 공급가 가져오기 전 확인사항

이 문서는 공급사 원가표(CSV)로 **옵션(품목)별 공급가를 수정**하려는 사용자를 위한 안내입니다.
가장 먼저 확인할 것은 CSV 형식이 아니라 **쇼핑몰의 ‘공급가 관리 방식’ 설정**입니다.

## 한 줄 요약

> 품목별 공급가 수정이 `422 Supply price by item cannot be modified.` 로 거부되면,
> 쇼핑몰의 **‘공급가 관리 방식’** 을 **‘상품 단위’ → ‘품목 단위’** 로 바꿔야 합니다.

## 왜 필요한가

Cafe24의 품목 수정 API(`PUT /api/v2/admin/products/{product_no}/variants/{variant_code}`)는
`supply_price`(공급가)를 받을 수 있지만, 쇼핑몰이 **‘공급가 관리 방식 = 상품 단위’** 이면
품목 단위 공급가 자체를 관리하지 않기 때문에 API가 요청을 의미상 거부합니다.
이때 품목 조회 결과의 `supply_price`는 모두 `null`로 내려옵니다.

- 증상 1: 품목 조회에서 모든 품목의 `supply_price`가 `null`
- 증상 2: 품목 공급가 수정 시 `422 Supply price by item cannot be modified.`
- 증상 3: (옵션 없는 단일 품목 상품) `422 Single product cannot be modified.`

이 동작은 앱 승인·권한 문제가 아닙니다. `mall.write_product` scope만 있으면 되고 별도 신청은
필요 없습니다. 실제로는 **쇼핑몰 설정에 달려 있습니다.**

## 설정 경로

`Cafe24 관리자 > 쇼핑몰 설정 > 상품 설정 > 상품 판매정보 설정`

(몰에 따라 ‘상품 설정 > 상품 관련 설정’ 아래에 보일 수 있습니다. 내부 페이지 경로 예:
`/admin/php/shop1/m/mall_manage_info_f.php`)

설정 화면의 **‘공급가 관리 방식’** 항목:

- **상품 단위 (기본)** — 상품 1개당 공급가 1개만 입력합니다. ← 이 상태면 품목 수정이 거부됩니다.
- **품목 단위** — 조합 일체/분리선택형 상품의 각 품목마다 공급가를 다르게 입력할 수 있습니다.

‘품목 단위’를 선택하고 **저장**하면 확인 대화상자가 뜹니다:
“공급가 관리 방식을 ‘품목 단위’로 변경하시겠습니까? · 이전 입력값이 있다면 복원되니 확인해 주세요”.
저장 후 “상점운영방식의 설정이 변경되었습니다.” 알림이 나옵니다.

## 헷갈리기 쉬운 점 — ‘판매가 계산 기준’은 다른 설정입니다

같은 화면에 있는 **‘판매가 계산 기준 설정’**(`use_supply_price` / API의
`calculate_price_based_on`)은 공급가 관리 방식과 **별개 항목**입니다. 품목별 공급가를 쓰더라도
판매가 계산 기준을 ‘공급가’로 둘 필요는 없습니다. 두 설정을 혼동하지 마세요.

| 설정 | 값(예) | API 노출 |
|---|---|---|
| 공급가 관리 방식 | 상품 단위 / 품목 단위 | 미노출(관리자 UI 전용) |
| 판매가 계산 기준 설정 | 공급가 / 기본몰 판매가 / 상품가 / 공급가 대비 마진율 / 판매가 대비 마진율 | `GET /products/setting`의 `calculate_price_based_on` |
| 마진율 기준 | 공급가 대비 / 판매가 대비 | `standard_price_type` |

## 전환 후 영향

- 품목별 공급가를 쓰게 되므로, 이미 상품 단위로 입력한 공급가가 있는 상품은 값을 다시 확인하세요.
  (전환 시 “이전 입력값이 복원될 수 있으니 확인” 안내가 나옵니다.)
- ‘판매가 계산 기준’이 ‘공급가’ 또는 ‘공급가 대비 마진율’이면, 품목 공급가를 바꾸면 **판매가가
  재계산될 수 있습니다.** 가격 정책을 확인한 뒤 진행하세요.
- 옵션 없는 **단일 품목 상품**은 ‘품목 단위’로 바꿔도 품목별 공급가 수정이 지원되지 않을 수
  있습니다. 옵션이 있는 상품을 대상으로 하세요.

## 동작 확인 방법

설정을 바꾼 뒤 아래 순서로 확인합니다.

1. 품목 조회에서 `supply_price`가 `null`이 아닌 값으로 보이거나, 수정 후 값이 반영되는지 확인합니다.
2. 한 품목만 변경 → 재조회로 반영 확인 → 원래 값으로 복원해 다른 필드(판매가·재고·추가금액)가
   그대로인지 확인합니다.

참고: Cafe24 품목 조회 API는 `Cache: Enabled` 라서 **수정 직후 재조회가 잠시 이전 값을 돌려줄 수
있습니다.** 값이 안 보이면 몇 초 뒤 다시 조회하세요. 이 앱은 쓰기 후 재조회로 반영을 판단합니다.

## 오류 메시지별 대응

| 메시지 | 원인 | 대응 |
|---|---|---|
| `Supply price by item cannot be modified.` | 공급가 관리 방식이 ‘상품 단위’ | ‘품목 단위’로 변경 후 재실행 |
| `Single product cannot be modified.` | 옵션 없는 단일 품목 상품 | 옵션이 있는 상품만 대상으로 |
| `품목이 삭제되었거나 찾을 수 없습니다.` | 품목 코드가 바뀌거나 삭제됨 | 최신 품목 목록으로 다시 검토 |
| `호출 한도에 걸렸습니다.` | Rate limit(40회/초) | 잠시 후 재시도(자동 백오프) |

## 되돌리기

‘공급가 관리 방식’을 다시 ‘상품 단위’로 되돌리면 품목별 공급가는 관리 대상에서 빠집니다.
운영 중인 몰에서 전환할 때는 가격·정산 영향을 확인하고 진행하세요.
