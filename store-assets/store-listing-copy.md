# 옵션별 공급가 CSV 가져오기 — 스토어 등록 카피 (심사/스토어용)

> `cafe24-option-detail`·`cafe24-return-photo`의 스토어 에셋 파이프라인을 재사용했다.
> 아이콘·배너는 `store-assets/icon-banner.html` → Playwright 렌더,
> 스크린샷은 `store-assets/render-screenshots.mjs`(앱 전용 Postgres에 합성 데이터 시드)로 만든다.
> 상세 설명은 `store-assets/detail-images.html`을 2x 렌더한 디자인 PNG를 `public/store/`에 두고
> `store-assets/store-detail.html`에서 참조한다.

## 앱 이름

- 저장소 이름: `cafe24-variant-cost-import`
- 판매 상품명: **`옵션별 공급가 CSV 가져오기`** (39 bytes / 13자)
  - 대안: `공급가 CSV 가져오기`, `옵션 공급가 일괄 가져오기`, `원가표 CSV 공급가 수정`
  - 스토어 안에서는 스토어명(온누리문방구)이 붙으므로 상품명에 `카페24`를 넣지 않는다.

## 한 줄 소개

> 공급사 원가표 CSV를 품목 코드로 매칭해, 바뀔 옵션별 공급가를 미리 검토한 뒤 한 번에 반영합니다.

## 상세 설명 (텍스트판)

```
공급사 원가표 CSV를 옵션별 공급가로, 검토하고 한 번에

Cafe24의 상품 업로드 양식에는 품목(옵션)별 공급가 열이 없습니다. 그래서 옵션마다 공급가가
다른 상품은 원가표를 받아도 일괄 수정이 어렵습니다. 이 앱은 공급사 원가표 CSV를 올려 품목
코드로 매칭하고, 바뀔 값만 검토한 뒤 옵션별 공급가를 반영합니다.

동작 순서
1. 원가표 CSV(variant_code,supply_price 또는 상품목록 내보내기의 상품코드·공급가)를 올립니다.
2. 품목 코드를 정확히 매칭합니다. 앞자리 0과 문자열을 보존하고, 상품명 유사도로 매칭하지 않습니다.
3. 변경/동일/오류 건수와 행별 변경 전·후 공급가를 미리보기로 확인합니다.
4. 중복 코드·미매칭·잘못된 숫자가 하나라도 있으면 확정이 막힙니다.
5. 확정한 작업만 실행하고, 실행 직전 재조회로 충돌을 확인한 뒤 행별 결과를 남깁니다.
6. 필요하면 성공한 행을 변경 전 값으로 되돌리는 복원 검토를 별도로 실행합니다.

안전 범위
- 요청 본문에는 공급가(supply_price)만 담습니다. 판매가·재고·설정·추가금액은 보내지 않습니다.
- 빈 공급가는 0으로 해석하지 않습니다. 0원은 명시적 입력으로 허용하되 주의로 표시합니다.
- 음수·통화 기호·천 단위 구분자·소수·지수 표기는 오류로 처리합니다.
- 파일 내용 해시로 검토 버전을 묶어, 파일이 바뀌면 이전 확정과 연결되지 않습니다.
- 원가 데이터는 영업정보이므로 일반 로그에 원가·원본 파일·토큰을 남기지 않습니다.

사용 전 확인
- 쇼핑몰의 '공급가 관리 방식'이 '품목 단위'여야 합니다. '상품 단위'이면 품목별 공급가 수정이
  422 Supply price by item cannot be modified. 로 거부됩니다.
- Cafe24 관리자 > 쇼핑몰 설정 > 상품 설정 > 상품 판매정보 설정에서 '품목 단위'로 바꿔 주세요.
- 옵션이 없는 단일 품목 상품은 품목별 공급가를 지원하지 않을 수 있습니다.
```

## FAQ (폼 입력용)

| 질문 | 답변 |
|---|---|
| 설치 후 바로 공급가가 바뀌나요? | 아닙니다. CSV를 올리면 먼저 검토(미리보기)만 만들고, 변경 전·후 값을 확인한 뒤 확정해야 실행됩니다. |
| 어떤 CSV 형식을 지원하나요? | `variant_code,supply_price` 형식과 Cafe24 상품목록 내보내기(`상품코드`·`공급가`)를 자동으로 구분해 읽습니다. |
| 옵션별 공급가 수정이 422로 거부됩니다. | 쇼핑몰의 ‘공급가 관리 방식’이 ‘상품 단위’이기 때문입니다. ‘품목 단위’로 변경한 뒤 다시 시도하세요. |
| 상품명이 비슷하면 자동으로 맞춰주나요? | 아니요. 품목 코드가 정확히 일치하는 행만 반영합니다. 상품명·옵션명은 검토 화면의 참고 정보입니다. |
| 잘못 반영했을 때 되돌릴 수 있나요? | 성공한 행에 한해 변경 전 값으로 복원하는 검토 작업을 별도로 제공합니다. |
| 판매가나 재고도 바뀌나요? | 바뀌지 않습니다. 요청에는 공급가만 담고 판매가·재고·추가금액은 건드리지 않습니다. |
| 엑셀(.xlsx) 파일도 올릴 수 있나요? | CSV만 지원합니다. 엑셀은 ‘CSV UTF-8’로 저장해 올려주세요. |
| 한 번에 몇 건까지 처리되나요? | 파일 크기·행 수 한도가 있고, 몰 전체 품목은 상품 수 상한 안에서 조회합니다. 초과 시 화면에 안내됩니다. |
| 옵션 없는 단일 상품도 되나요? | 품목별 공급가를 지원하지 않을 수 있습니다. 옵션이 있는 상품을 대상으로 사용하세요. |
| 어떤 권한을 요청하나요? | 상품 조회·수정(`mall.read_product`·`mall.write_product`)과 상점 조회(`mall.read_store`)뿐입니다. 주문·회원 정보는 조회하지 않습니다. |
| 앱을 삭제하면 어떻게 되나요? | 저장된 Cafe24 접근 토큰을 삭제합니다. 검토·실행 기록은 몰별로 보관됩니다. |

## 남은 작업 (스토어 등록 전)

1. 개인정보처리방침 페이지가 필요하면 `/privacy`를 추가하고 폼에 URL을 넣는다(현재 미구현).
2. 테스트몰(`onnurimun`) 실측과 파일럿 몰 확보.
3. 판매 상품명·카테고리·가격(무료) 최종 확정.
4. 제출 전 실제 사용 몰 사례(295×166)는 파일럿 몰이 생기면 추가.
